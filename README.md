# Artificial Inquiries – Exercice 2.a : All the Things You Do

# Description de l'exercice

L'exercice 2.a « All the Things You Do » consiste à identifier et à lister les différentes tâches réalisées dans le cadre de son activité professionnelle.

L'objectif est d'obtenir une vue d'ensemble de ses pratiques professionnelles avant d'étudier la place que les LLM peuvent y occuper.

Pour aider l'utilisateur à identifier ses tâches, l'exercice l'invite notamment à réfléchir :
- aux tâches qu'il réalise fréquemment ou rarement ;
- aux tâches qu'il aime ou n'aime pas faire ;
- aux tâches qu'il a tendance à repousser ;
- aux tâches qui demandent beaucoup de temps ;
- aux tâches considérées comme simples ou nécessitant une expertise.

Chaque tâche possède un identifiant afin de pouvoir être réutilisée dans les autres exercices du protocole Artificial Inquiries.

# Proposition d'outil numérique

L'exercice papier sera transformé en une application permettant à l'utilisateur d'ajouter et d'organiser ses différentes tâches professionnelles.

Pour chaque tâche, l'utilisateur pourra renseigner plusieurs informations :
- nom de la tâche ;
- fréquence ;
- appréciation de la tâche ;
- temps nécessaire ;
- tendance à procrastiner ;
- niveau de difficulté ou d'expertise.

Les tâches enregistrées seront ensuite affichées dans un tableau afin de permettre à l'utilisateur d'avoir une vue globale de ses activités professionnelles.

# Solution technique envisagée

L'outil pourra être réalisé sous la forme d'une application web.

Technologies envisagées :
- HTML / CSS pour l'interface ;
- JavaScript pour les interactions ;
- une base de données pour enregistrer les tâches.

Cette solution permettra de transformer l'exercice papier en un outil numérique interactif et facilement utilisable.
